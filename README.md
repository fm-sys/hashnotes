# Hashnotes

_Hashnotes_ is your simple notepad. Nothing gets stored on any servers. 
Instead, the whole text is stored inside the hash part of the URL, which is only processed locally by the browser.
This makes it well suited to make short (or longer) notes while you're browsing without the need to switch between different apps.

> [!TIP]
Configure your browser to remember opened tabs across sessions, so neither your tabs nor notes ever get lost. 🚀
